# Business Entity Resolution Challenge

A runnable experiment pipeline is in [`code/business_entity_resolution`](code/business_entity_resolution/README.md).
It implements cleaning, five retrieval routes, learned candidate fusion, hyperparameter search,
logistic regression, boosted trees, a fine-tuned cross-encoder, audit reports and validated challenge outputs.

No challenge dataset is included. Put the seven TSV files in `dataset/train/` and `dataset/test/` when available.
The synthetic data generated by the smoke test is only for software verification.

From this folder, with Python 3.12:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r code/business_entity_resolution/requirements.txt
python -m pip install -e code/business_entity_resolution --no-deps

# One explicit download of pretrained model weights, not business records:
ber download-models --directory models

# Once the dataset is present, run the complete experiment:
ber run --data-dir dataset --config code/business_entity_resolution/configs/default.yaml --run-dir runs/experiment_001
```

The full configuration runs all three matchers separately. It does not combine them automatically.
Open `runs/experiment_001/reports/model_comparison.tsv` and `reports/model_disagreements.tsv` to compare them.
The selected submission is `runs/experiment_001/output/matching_results.tsv`; its actual matcher input set is
`runs/experiment_001/output/candidate_pairs.tsv`. Separate predictions for each model are under `output/models/`.

Without the dataset or downloaded pretrained weights, exercise all branches using a tiny local transformer:

```sh
ber smoke --directory runs/smoke_local --config code/business_entity_resolution/configs/default.yaml
python -m pytest code/business_entity_resolution/tests -q
```

Use a new run directory for each experiment. See the project README for hyperparameters, reports,
offline replay, submission packaging, limitations and the exact evaluation protocol.
